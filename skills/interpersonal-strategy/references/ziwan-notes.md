# 紫丸的现实视角与使用限制

《紫丸》（锵锵三分钟）主要采用男性视角的两性叙事，含大量性别本质化、择偶市场分类和未经验证的生物学解释。它在本技能中只作为一个作者视角；以下保留的内容均经过改写，不把其分类作为认识用户或伴侣的默认模型。

## 可转成个人行动的启发

| 原书位置（PDF页序） | 原文讨论的主题 | 本技能采用的做法 |
|---|---|---|
| 序言第7页；第19节，第76–78页 | 完成结婚与找到合适伴侣的区别；关系满足多种需要 | 先澄清想要社交、约会、稳定伴侣、婚育还是退出，再按目标选择行动；允许单身与不婚 |
| 第20节，第80–81页 | 单身时的爱好、社交圈、健康与生活安排 | 建立真实朋友、兴趣、生活秩序和支持，不把某个人当作唯一出口；恋爱中也可保留这些资源 |
| 第22节，第89页 | 多维度、真实的社交展示 | 简介和聊天使用真实经历、兴趣、生活细节，不虚构财富、追求者、人设或未来承诺 |
| 第23节，第91–93页 | 外表、穿着、体态 | 按用户意愿改善整洁、舒适和场景适配，与倾听、可靠和真实表达一起考虑；不保证吸引或同意 |
| 第24–26节，第94–101页 | 长期关系的条件、阶段与陪伴 | 双向讨论时间、金钱、亲密、忠诚约定、工作、家务和未来，观察承诺落实；不预设男供养女服从 |
| 第27节，第102–103页 | 对方缺乏吸引时的选择 | 接受明确拒绝，停止追加礼物或追逐，把精力投入生活与新的双向机会，不要求特定对象回报成长 |
| 第29节，第108页 | 伴侣清单中的储蓄、反思、归因 | 改成双方都适用的行为问题：如何安排钱、是否履约、争执后是否承担责任；舍弃人群排名 |
| 第30节，第110–112、114–116页 | 很难完整了解对方经历，信任与披露 | 承认信息缺口，讨论与共同决定相关的当前约定和责任；尊重隐私，不盘问或推测性史 |
| 第53节，第183–187页 | 恋爱与婚姻条件变化 | 升级关系前公开讨论预算、城市、事业、婚育和节奏；条件冲突先协商，不直接认定算计 |
| 第54节，第188–189页 | 确认、退避、忽近忽远等亲密反应 | 只描述触发、感受、行为与回应；依恋是待验证的视角，不凭聊天分型、定罪或预测未来 |
| 第59节，第199–200页；第66节，第214–215页 | 再婚、子女责任、前任边界与自主选择 | 澄清共同养育、时间、经济责任及必要联系；不要求有子女者与前任完全失联，不替用户作法律判断 |

上表的做法是本技能设计的转换，不是对原书全部结论的认可。若用户只想借书中的“市场”比喻理解选择，可以讨论机会、信息与取舍；不据此给人的尊严、年龄或性经历标价。

## 不继承的规则

| 来源 | 不采用的推论 |
|---|---|
| 第16–18节，第68–75页 | 不以性别“程序”合理化不忠，不以月经周期推断个体自由意志或选择接近时机 |
| 第22节，第88–90页 | 不把情绪操控、进入私密空间或“处理阻碍”转成恋爱教学；没有明确同意就停止推进 |
| 第29节，第106–109页 | 不用职业、学历层次、家庭出身、年龄差、外貌或性经历作普遍人格排名和一票否决表 |
| 第30节，第112、114–117页 | 不通过表情、照片、音乐、旅行或叙事细节“测谎”；披露受侵害经历本身不是操控证据 |
| 第28、54节等，第104–105、188–189、191页 | 不把不生育、依恋、脑结构、童年或母爱与疾病的作者解释当医学结论 |
| 第40节，第141–145页 | 不从性工作或职业经历推断一个人永久缺乏爱、无法建立关系或有身体损伤 |
| 第31、64–65节，第119、210–213页 | 不用收入、能否吸引他人或性欲评价人的尊严与人生价值，不采纳羞辱和宿命论 |
| 结语，第216–221页 | 不自称凭这些理论预测某人的一生或看透全部动机 |

需要判断某个医学、心理学或群体统计主张是否为真时，应另做有来源的事实核查。用户提供本书不代表已同意书中的价值排序，也不代表其持有作者的性别立场。

## 与其他模块怎么结合

用本书讨论目标、自我建设与现实条件时，接着读 [dating-and-mate-choice.md](dating-and-mate-choice.md) 的需求、适配和约定。出现人格推断时，转到 [psychology.md](psychology.md) 的行为证据与竞争解释。涉及欺骗或施压时，查 [strategy-catalog.md](strategy-catalog.md)，但不能因一个人属于作者的某类画像就给其匹配套路。
