# 十族 111 条策略：候选检索与防御索引

依据用户提供的《社交博弈策略全识别手册：十族·111种》整理。编号、名称及起始页按 **PDF 正文**；页数是阅读器从 1 开始计数的实际 PDF 页序，不是目录标注页数。可观察模式是对正文“核心解释 / 识别手法”的简短概括；防御动作是本 skill 的重新设计，不能当成原书原话。

这里用于**检索候选解释，不用于给人定罪**。热情、沉默、忘事、赞美、拒绝、保密、谈价格、依法投诉或有疾病，本身都不证明操纵。先核对具体事实、上下文、约定、资源约束及其他解释，再关注是否存在有意误导、反复越界、惩罚拒绝、单向转嫁代价或剥夺选择；未知动机就保留未知。持续模式能增加疑点，**严重威胁、暴力、勒索或重大隐私侵害出现一次，也足以先采取保护行动**，无需等到集齐条目。

先问三个问题：我缺少什么关键信息？哪些情绪或时间压力正在影响决定？收益、责任及退出代价各由谁承担？应对优先恢复信息、时间、边界和替代选项。证据应来自本人可访问的记录及正常核实，不能以防御为由秘密入侵、监视、造谣或报复。若直接对质可能增加危险，先保护安全和支持网络。涉及具体法律权利、程序或心理诊断时，另核验适用信息；原书命名不是法律或临床结论。

优先找原始材料及完整语境，避免把中间人的版本当全部事实。

## 检索后的最小行动

一次只选择与事实最贴近的 1–3 个候选，不要把正常关系套成 111 项审讯。写清：具体发生了什么、还缺什么信息、哪项边界受到影响、有哪些其他解释。再选一个可执行动作，例如核对原约定、争取考虑时间、书面确认职责、停止新增投入或寻求支持。观察的是信息是否更清楚、拒绝是否被尊重、修复是否兑现、本人是否恢复选择权。

原书下篇（PDF 第 96–100 页）强调证据、规则、替代选项与能力，而不仅是认出招名。本 skill 保留这一行动方向，同时不把当面对质、公开摊牌或某种追责程序设为所有人的必选；具体方式须符合当事人的安全、授权与现实条件。
