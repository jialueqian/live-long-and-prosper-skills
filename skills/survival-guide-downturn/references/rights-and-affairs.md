# 法律救济、反诈与身后事务

本模块按中国大陆常见办事场景分流。先确认事件发生地、劳动或居住地、时间线与用户想要的结果；其他法域另查当地制度。
提供取证、官方入口与待核事项，不从几句话判断胜诉、犯罪成立或继承份额。紧急人身危险、正在发生的诈骗优先报警。

## 1. 先保留材料，再选择通道

制作一页时间线：发生了什么、对方是谁、哪天发生、损失或诉求是什么、已有何种材料。
保留合同、订单、工资流水、工作安排、聊天原文、转账凭证、通知与送达记录；保留原设备和可核对的完整上下文。
截图用于快速展示，原始记录用于核对；备份与原件分开，不剪接、伪造，也不擅自侵入他人账号取证。
录音、个人信息与证据公开的合法边界需结合场景确认；提交时只提供必要信息，公开分享前脱敏。
给文件按“日期—事件—来源”编号，保留提交清单、工单、受理或收件凭证。需要保全证据或财产时尽早询问法律服务机构。

## 2. 免费官方咨询与办事入口

下表是查询和分流入口，不代表已经核实个人资格，也不承诺免费律师、补贴或退款必然获批；电话通信费用按运营商规则。

| 问题 | 起点 | 咨询时问什么 |
| --- | --- | --- |
| 欠薪、社保、失业与就业服务 | 12333、[全国人社政务服务窗口](https://12333.gov.cn/ggfwstatic/hrss-service-window/)及当地人社部门 | 有管辖权的机构、申请材料、具体事项期限、线上或现场渠道 |
| 法律咨询、调解、法律援助 | 12348、[中国法律服务网](https://www.12348.gov.cn/sfbMobile/app/page/home/public/public_home.html)及当地公共法律服务中心 | 案由、援助范围与资格、需要什么证明、怎样申请 |
| 消费纠纷、价格或经营违法线索 | 12315、[全国12315平台](https://www.12315.cn/) | 被投诉经营者、消费事实、请求及管辖部门；投诉与举报分别如何处理 |
| 低保、临时救助、生活无着 | 当地民政部门、乡镇或街道、救助管理机构 | 当前困难能否申请、属地与材料要求、紧急帮助怎么安排 |
| 正在被骗、已转款或人身危险 | 110及当地公安机关 | 报案、紧急止付或其他处置需要哪些信息 |

消费渠道依据：[市场监管总局公布的12315入口](https://www.samr.gov.cn/hd/index.html)。救助与补贴的金额、缴费条件、次数、期限均须核对当地现行指南，不写成全国统一待遇。
示例：被欠两个月工资且本周交不起房租，可同时准备讨薪材料并询问临时救助；不要等待一个程序结束后才解决生活问题。

## 3. 劳动争议分流

先核对劳动关系或劳务关系、实际工作地点、单位主体、合同与用工证据；平台接单、外包、派遣不能只按合同标题判断。
对欠薪、未缴社保等问题，可先向当地人社部门咨询劳动保障监察或对应经办渠道；涉及劳动关系、解除、补偿等争议，核对调解仲裁路径。
整理入职离职日期、约定与实付工资、考勤、工作指令、解除通知和社保记录；按月份列明金额与计算依据。
协商时以可留存方式提出具体诉求，约定履行日期；不为换取口头承诺而轻易签署“全部结清”或放弃权利的文件。
调解、监察与仲裁各有受理范围；不要推定提交一次投诉就自动保住所有程序期限。
法律援助是否适用由机构依事项与条件审查；拿到裁决或决定后，立即核对后续起诉、复核或执行的要求。
依据：[人社部中国就业网公布的《劳动争议调解仲裁法》](https://chinajob.mohrss.gov.cn/c/2022-07-15/356212.shtml)；使用时补查现行法律、司法解释及当地受理指南。

## 4. 期限必须和案由一起查

逐项记录“什么请求—依据—起算事件—中止/中断或例外—最迟行动—受理机构”，缺一项就不宣布期限结论。
一般民事诉讼时效、劳动仲裁时效、行政救济期限、执行申请、保证期间等不是同一概念，不能共用一张倒计时表。
《民法典》第一百八十八条设一般诉讼时效，同时保留法律另有规定；第一百九十二条规定届满后的抗辩，并非所有实体权利自动消失。
依据：[国家网信办公布的《民法典》](https://www.cac.gov.cn/2020-06/01/c_1592561777268319.htm)。实际起算、中断、请求类型及例外须结合事实核实。
劳动争议也有不同起算、中断、中止及在职欠薪规则，不能把所有请求都写成“离职后统一倒计时”。
接近期限、日期不清或已经逾期时，仍应立即带材料咨询；不要自行认定毫无救济，也不要承诺一条催款消息必然使期限重算。
医疗死亡争议涉及的尸检规则有特定适用场景，不把其时间要求推广到全部死亡；立即问处理机构或律师并保留提出请求的时间。
报案后索取并保存可出具的受理、处理与送达材料；不立案或其他决定的救济，以具体文书、程序与现行规定核对。

## 5. 反诈：停止损失，独立核验

高收益催转账、刷单垫资、解冻费、退款前充值、共享屏幕操作银行、索取验证码、“安全账户”和有偿走账，都应暂停并独立核验。
正规培训或经营投入也可能收费，单凭先付钱不能定诈骗；核对主体、合同、交付、退款和是否依赖拉人头，而不是听对方保证。
脸、声音、群聊身份和来电显示都可能伪造。涉及借钱或转账，挂断后用已有号码或机构官网查到的渠道重新联系。
不外借银行卡、手机卡或支付账号，不代收代转不明资金；不随意挂名公司负责人、担保或签空白文件，具体责任须按事实判断。

发现被骗或刚转账时：
1. 立即停止继续付款，拨110报案，按要求提供转账时间、金额、交易号、收款信息、联系方式与完整聊天记录。
2. 同时联系银行或支付平台官方客服，说明疑似诈骗并询问可采取的措施；有另一人在场时可分工，避免互相等待。
3. 保留原设备与证据，记录报案和沟通凭证；止付、冻结与追回需按权限和事实处理，不保证成功，也不说超过某个窗口就无事可做。
4. 不付“追回保证金”“黑客找回费”，不向自称办案者提供验证码或转入所谓安全账户；疑似反诈来电可独立联系警方核验。

96110用于反诈预警劝阻等服务，不替代紧急报警；警方提醒见 [银川公安反诈说明](https://police.yinchuan.gov.cn/xwdt/jfts/202604/t20260423_5224097.html)。

## 6. 生前准备：让事务可找到、可合法办理

制作资产与义务目录：银行/证券/保险/公积金机构、房产线索、债权债务、订阅、业务联系人、重要文件存放处和更新日期。
数字目录记录平台名称、账号识别线索、资产类型、继承或纪念账户入口、双重验证与恢复材料的保管位置；目录本身不放全部密码、验证码、私钥或助记词。
按需要使用可信密码管理器的紧急访问机制，或将恢复材料加密/密封分开保管，约定访问条件、受托人和备用方案，并验证不会因单一设备失效而无法使用。
告知可信的人“目录在哪里、遇到何种事件联系谁”，不把一份可直接接管所有账户的明文文件普遍共享。
明确金融账户、平台数据与数字财产可能有不同规则；技术上能登录不等于有权转账或处分，应走平台与机构的合法办理渠道。
涉及遗嘱、未成年人照护或复杂财产时，向法律服务机构核对有效形式、共同财产边界、执行与保管安排；不承诺普通备忘录等同有效遗嘱。
指定协助人不等于赋予其无限处置权；可撤销、限定权限并定期复核。

## 7. 去世后的事务分流

先确认是否仍有救治可能；未经确认的危急情况先联系急救。突发、意外、死因不明或涉嫌违法时联系公安与医疗机构，按指引保护现场。
已经确认死亡后，依据死亡地点与性质，向救治医院、属地卫生机构或公安询问证明办理；不预设所有非正常死亡只能由同一部门出证。
有死因争议时，尽快表达异议、咨询病历封存和检验程序，在相关程序明确前不要草率同意影响调查的处置。

| 事务 | 要做的事与注意点 |
| --- | --- |
| 证明材料 | 问清死亡证明、身份与亲属关系材料、原件份数及数据共享；电子或复印件是否接受由受理机构确认 |
| 殡葬安排 | 从当地民政或政务渠道核实服务机构、必需项目、价格清单与惠民政策；保留收费明细和票据 |
| 户籍及联办 | 查询当地“个人身后一件事”或分别办理，核对顺序、材料与期限，不照搬其他城市流程 |
| 财产与待遇 | 分别查询银行存款、证券、保险、公积金、社保账户、遗属待遇和雇主相关款项；并非每一项均属遗产 |
| 债务与继承 | 整理遗嘱、财产、债务与利害关系人，区分共同财产、受益人安排和遗产；先核对权利义务再处分 |
| 账号与订阅 | 按平台合法渠道申请数据处理、纪念、继承或注销，先确认需要保留的证据与资料，避免过早删号 |

示例：[北京个人身后一件事指南](https://banshi.beijing.gov.cn/pubtask/bhyjs/grsh/grshjd.html)展示了证明、户籍、公积金等联办事项；仅作本地查询示例，不证明其他地区条件一致或某个家庭符合资格。
不要求家属先自行替逝者清偿全部债务，也不建议隐匿或转移遗产；遇到争议由法律服务机构核对遗产范围、清偿和继承责任。

## 8. 输出与来源边界

按问题需要说明今天应做的动作、材料、官方入口、待核期限及分工；用户仅问单项时只给相关流程。
本模块默认提供准备与指引；发送投诉、联系亲属、提交材料、登录账号或处分财产须另有明确且范围清楚的授权。
