# 来源与证据使用

本版定向核验日期：2026-10-12。这里记录设计依据与读取范围；不宣称读完所有书、全面验证每条人生策略，或完成全部现行法规审查。

## 分清材料能证明什么

| 材料 | 可支持什么 | 不能据此推导什么 |
| --- | --- | --- |
| 用户提供的事实 | 其报告的处境与目标；重要事项可继续核实 | 猜测未提供的收入、意愿、诊断或他人动机 |
| 当前官方规则、合同与办事目录 | 所涉条款、服务及适用条件，注明日期和地区 | 人人符合资格；目录存在就代表已经办理；规则证明生活策略有效 |
| 适合问题的研究 | 在对应人群、方法和结果范围内的发现 | 相关就是因果；群体均值决定个人；一篇论文覆盖全部生活问题 |
| 作者观点与经验 | 可供讨论的框架与工具 | 已验证的定律、临床诊断、固定配置比例 |
| 网友案例和讨论 | 情境、反例、可能的尝试方法 | 点赞等于有效；受欢迎的案例具有代表性 |
| 本技能综合设计 | 明确标注的建议、情景与试验参数 | 多位作者共同提出，或已获得独立实证验证 |

不把法条与随机试验混排为同一种“A级”；按当前主张选证据。相同作者的书、文章和访谈相互解释，不算独立重复验证。
