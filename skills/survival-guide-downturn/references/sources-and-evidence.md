## 分清材料能证明什么

| 材料 | 可支持什么 | 不能据此推导什么 |
| --- | --- | --- |
| 用户提供的事实 | 其报告的处境与目标；重要事项可继续核实 | 猜测收入、意愿、诊断或他人动机 |
| 当前官方规则、合同与办事目录 | 所涉条款、服务及适用条件，注明日期和地区 | 人人符合资格；入口存在就是已办理；规则证明生活策略有效 |
| 适合问题的研究 | 对应人群、方法和结果范围内的发现 | 相关就是因果；群体均值决定个人；一篇论文覆盖全部生活问题 |
| 作者观点与经验 | 可供讨论的框架与工具 | 已验证定律、临床诊断、固定配置比例 |
| 网友案例和讨论 | 情境、反例、可能的尝试 | 点赞等于有效；热门案例具有代表性 |
| 本技能原创或综合设计 | 明确标注的建议、情景与试验参数 | 多位作者共同提出，或已获独立实证验证 |

不把法条与随机试验混排为同一种“A级”。相近观点、同一作者多书、书与访谈的互释均不算独立重复验证；Money第13章引用Taleb，尤其不能算新增一项独立实证。原书转引研究不代表本轮核过那些研究。

“目录筛选”用于决定是否继续读；“正文阅读”指实际读过下列目标文字；“原页核对”指直接查看PDF图像、EPUB题图或相关插图；“未采用”表示本版不据该材料新增具体主张。提取成功、哈希一致与读过正文是不同事实。
