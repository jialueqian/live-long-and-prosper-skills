# 宏观背景与个人决定

仅在宏观变化确实影响本次生活决定，或用户明确要求结合宏观分析时读取。单纯解释LPR、社融或利率曲线不应引发全面人生诊断。

## 将框架、数据与推论分开

《见证逆潮》第2章讨论分工、生产要素所有权与分配，第3章讨论债务、杠杆与收入的反馈，第9–10章讨论收入及财富分化。本次回查了这些章节中的相关小节，仅将作者的解释框架用于提出问题：哪些行业、收入来源与负担可能受到变化影响？不把书中的因果论述当作已独立验证的定律，也不据此精确定位周期或预测个人命运。[实际阅读小节与采用范围](sources-and-evidence.md)

书中3.8–3.9也讨论金融的双面性与债务用途，不能将其简化为“所有负债都有害”。本次未独立核验书中的历史数字、图表及转引研究；需要引用时查原段落和原始统计。日本经验可提示情景与机制，不能推导中国必然持续低增长10–30年，或个人出海一定最有效。

## 需要当前信息时

在相关官方机构查具体指标，标明观察期、发布日期、地区、定义与来源。中国可查央行政策与金融统计、国家统计局就业与收入、财政和当地政策；涉及市场收益率还需核对期限和口径。[中国人民银行](https://www.pbc.gov.cn/)、[国家统计局](https://www.stats.gov.cn/)

区分数据公布滞后、修订及不同口径。联网不可用时，用明确的假设情景分析，不声称知道当前政策立场或最新数值。

## 避免机械映射

- 美债期限利差、LPR、政策利率、社融和中债期限利差衡量不同事项，不能互相替代。
- 一次倒挂、恢复正利差、降息或存款利率下降，都不能单独推出买房、借款、出售资产或加杠杆。
- 价格变化、现金流、偿债能力、期限及用户的实际用途一起影响决定。总体增长与个人机会也可能不同。
- 不填写缺少来源的领先月数、衰退概率、市场底部或固定历史均值。

## 回到家庭可承受的情景

比较收入稳定、收入下降、利息或生活成本改变等与本次问题有关的情景。说明哪个变量会改变选择，以及哪些行动无须猜中周期也有价值，例如核实合同、降低无法承受的固定支出、保留必要流动性。

宏观分析的产出是需要关注的条件及应对方案，不是“当前周期位置决定你该怎么活”的口令。具体财务问题交叉读取 [finance-and-insurance.md](finance-and-insurance.md)。
