# 财务安全、住房、保险与照护

用于现金紧张、失业、债务、买房、保障缺口或家庭照护决策。下列测算是规划工具，不是适用于所有人的资产比例或投资指令。
若吃饭、必要治疗、住所或人身安全已受威胁，先解决这些迫切需求，并同步查询救助；不得为了储蓄目标、提前还债或买商业保险而中断必要治疗。

## 1. 先算能否维持生活

只问影响当前决定的信息，金额可以用区间；无需索要身份证、账户号码或完整保单。

| 信息 | 需要核对什么 |
| --- | --- |
| 必需支出 | 食物、住所、基础水电交通、必要治疗、实际承担的赡养抚养 |
| 到期义务 | 最低还款、合同到期款、税费及已确定的大额支出，避免与生活费重复计算 |
| 稳定收入 | 税后到账、可持续性、到账日期；奖金、潜在客户和投资涨幅不当作确定收入 |
| 可用现金 | 现在能合法动用、能及时到账的金额；扣除别人的钱和已有专门用途的款项 |
| 共同风险 | 家庭收入是否依赖同一行业；谁需要照护，谁能在紧急时提供实际帮助 |

列出未来各月的支出与到账时间，找出最早缺钱的日期。账面资产充足也可能无法支付下周房租。
信息不足时先给填空表和条件方案，不按收入标签推定贫困、富裕或承受能力。

## 2. 按情景设计现金池

四类用途可以放在同一账户中记账，不要求开四个账户，也不把同一笔钱重复算成多层保障。

| 用途 | 金额怎样确定 |
| --- | --- |
| 日常流 | 覆盖下一次可靠收入到账前的必要支付 |
| 已知账单 | 已确定的续租、治疗、学费、税费等；注明日期与金额 |
| 应急缓冲 | 对失业、停工、照护中断等相关情景分别测算资金缺口 |
| 可承受损失的实验金 | 满足前三项后，用户愿意全部损失也不影响生活与责任的钱 |

可先用保守近似：`情景缺口 = 各月 max(0, 必需支出 + 到期还款 − 保守稳定收入) 之和 + 未重复计入的一次性必要支出`。
再单列与这个情景有关、尚未包含的突发支出。已有现金是否足够，要同时看总额和每笔钱的到账时点。
测算跨度由重新就业时间、收入季节性、健康、家庭支持决定；分别看短期中断和更久中断，不统一规定几个月。
示例（假设值）：每月必需支出5000元、最低还款1000元、停工后可靠收入2000元；按4个月情景，缺口为16000元。另有未计入的必要治疗3000元，总需求为19000元。
这不是推荐所有人存19000元；若收入恢复更慢、支出不同，应重算。长期现金目标还要考虑通胀、机会成本和真实生活愿望。
预留缓冲借鉴《The Psychology of Money》第13章“Room for Error”：计划可能失准，需要留出承受偏差的空间；该章也明说缓冲不能提供百分之百保证。四类用途、情景公式和示例是本技能原创规划工具，不是书中公式或统一储蓄标准。[书籍定位与限制](sources-and-evidence.md)

## 3. 保留探索，但不强制下注

《Antifragile》第11章的杠铃是把极低风险与高风险暴露分开，先限制毁灭性损失。书中90%保值现金、10%高风险证券是带有安全部分免受通胀侵蚀等假设的金融例子，不是标准资产配置；本技能借用的是“保护承受不起损失的部分，再给损失可控的探索留下空间”。第12章的试错讨论还要求下行有限、能识别并选取有利结果，不能仅因预算小就断言项目“反脆弱”。[书籍定位与限制](sources-and-evidence.md)
先检验最坏损失：钱、时间、健康、共同责任是否都能承受；不同实验可能同时失败，不能只看单项预算。
现金紧张、治疗或照护压力大时，可以暂时不投入资金，以访谈、练习、试做作品等方式探索。
安全垫充足且长期只防御时，讨论有时效的体验、技能和关系投入；不把现金越多当作人生越成功。
实验写清预算、截止日期、能证明需求的信号、退出条件；不借钱证明自己，不以“高凸性”包装投机。

## 4. 债务逐笔检查

为每笔债务记录余额、实际综合成本、月付、到期日、抵押物、担保人、逾期后果和提前还款条件。
先防止生活断供和严重的到期后果，再比较高成本债务；保留必要现金，避免提前还款后又借更贵的钱生活。
“生产性用途”不等于安全债务：设备可能闲置、技能可能卖不出去、出租资产可能空置；还款义务仍然存在。
新增债务前至少算收入下降、回款延迟、利率变化或资产卖不掉的情景，核对担保及个人责任范围。
月供占收入比例可以用于比较自身前后变化，不能单凭一个百分比断言安全或必须卖房。
已接近违约时，整理合同和现金表，尽早通过债权人官方渠道了解协商选项；不承诺一定能减免，不推荐“洗征信”或代办转贷。
必要时转法律救济与援助流程，见 [rights-and-affairs.md](rights-and-affairs.md)。

## 5. 买房与已持房产

先区分自住需求、家庭安定、通勤教育需求和投资期待；不把买房或租房预设为唯一正确答案。
用相同居住质量与相同持有跨度比较：首付机会成本、月供、税费、维护、租金、搬家成本和退出难度。
分别算正常收入、停工、家庭照护增加、无法及时出售的情景；共同出资与居住安排要明确权利和责任。
重大决定的观察期应服务于补齐信息；迫切住房需求或到期风险下，不机械等待12个月。
已经持有时比较继续持有、出租和出售的未来现金流，同时纳入交易成本、剩余贷款、空置维修和搬迁代价。
不要仅因账面亏损继续持有，也不要仅因房价下跌要求卖掉；不以“市场一定见底”阻止必要止损。
合同、产权、购房资格、贷款及税收政策按所在地现行规定核验；宏观信号不能代替这些具体检查。

## 6. 保险从实际缺口开始

先查基本医保有效状态、异地就医安排、单位与既有商业保障，再讨论尚未覆盖的损失。
参保信息可从 [国家医保服务平台](https://fuwu.nhsa.gov.cn/) 查询；这是办事入口，具体缴费、等待期、待遇及救助资格须查参保地现行指南。
已有严重疾病或正在治疗时，先落实诊疗与现有报销、医疗救助渠道；不能暗示今天投保就能覆盖已经发生的疾病。

| 需要承受的损失 | 核对问题 |
| --- | --- |
| 医疗自付 | 哪些医院、药品和治疗在范围内？免赔额、比例、限额、等待期及除外是什么？ |
| 死亡后家属生活 | 谁依赖这份收入？未来必要支出、债务与已有资产保障相差多少？ |
| 停工或长期照护 | 现金能撑多久？单位待遇、社保、家庭照护和保险各能承担什么？ |
| 意外及特定疾病 | 定义、触发条件与个人实际暴露是否匹配？是否与已有责任重叠？ |

按用户最难自担的损失、可投保条件与长期预算决定先后；不统一规定“医疗＞重疾＞寿险”，也不要求人人必须买同一类产品。
阅读健康告知并如实作答，保留投保与核保记录；拿不准的问题向保险公司官方渠道书面确认。
比较总保费压力、续保条件、责任免除与理赔要求，不按营销保额或“每年只要几百元”判断适合。

**保险期间与续保必须区分：**
- 一年保险期间只说明本次合同期限，不能据此判断整个保障能延续多久。
- 《健康保险管理办法》第四条：长期健康保险包括保险期间超过一年，或虽不超过一年但含保证续保条款的健康保险；短期健康保险为一年及以下且不含保证续保条款。
- 购买时分别核对保险期间、保证续保期间、保证期结束后的处理、费率调整条件、停售与重新核保规则；“可续保”不等于“保证续保”。
- 保证续保不等于保费永远不变；长期医疗险可能依合同约定调整费率，需读具体调费条款。
- 依据：[上海金融部门转载《健康保险管理办法》](https://jrj.sh.gov.cn/YWTBZCCX166/20191113/0031-157191.html)第四、二十、二十一条；[金融监管总局短期健康险通知](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=958198)补充短期险“不保证续保”要求。前者全文已读，后者本次仅核到官方索引；这些定义不能证明某款产品适合某个人。

## 7. 赡养、抚养与长期照护

照护预算同时包含现金、时间、交通、误工及替班；先与被照护者和共同承担者确认意愿与实际能力。
列出当前稳定支出、可能升级的照护需求、可用公共服务、家庭分工及备用联系人；不要默认为某一个人无限承担。
教育支出区分必要费用、可选培训与长期愿望，不以固定教育金比例挤占基本生活或治疗。
比较居家、社区和机构照护时，询问服务内容、资质、可实际提供的护理、费用变化、退出条件和应急处理。
养老、长护险、教育资助、低保与临时救助按当地官方指南查资格，不能把政策入口当作已经批准的待遇。
示例：老人每周复诊影响工作，先试排班、社区服务和交通协助，记录现金与误工变化，再决定是否需要长期雇护工。

## 8. 交付与复盘

按问题需要给现金时间表、最相关的风险情景、近期动作及复盘触发条件；简单问题不强制套表或限制行动数量。
每项写清谁做、何时完成、预计成本及完成证据；收入变化、疾病、家庭责任或合同条件改变时立即重算。
