# Live Long & Prosper Skills

面向日常生活选择与人际关系的个人 Agent Skills 集合。按具体问题使用相关技能，不必同时加载所有内容。

## 技能目录

| 技能 | 用途 | 入口 |
|---|---|---|
| survival-guide-downturn | 经济下行或人生转折中的现金流、工作、居住、照护、健康、关系与权益取舍 | [SKILL.md](skills/survival-guide-downturn/SKILL.md) · [详细说明](skills/survival-guide-downturn/README.md) |
| interpersonal-strategy | 人际社交、恋爱与择偶、利益谈判、心理模式分析和逐轮对话演练 | [SKILL.md](skills/interpersonal-strategy/SKILL.md) |

## 使用方式

将所需的完整技能文件夹放入所用工具支持的技能目录，保留 `SKILL.md`、`references/` 及其他资源的相对位置。每个技能可以独立使用。

例如：

- “用 survival-guide-downturn 帮我比较留在当前城市和搬到低成本城市的取舍。”
- “用 interpersonal-strategy 帮我做两周同事交往计划，每天最多15分钟。”
- “用 interpersonal-strategy 扮演刚认识的约会对象，你先开口，我回复，等我说结束再反馈。”

## 资料与范围

技能内包含有选择的原创摘要、来源定位和行动设计，不包含电子书、扫描件、整书OCR或个人关系档案。作者观点与技能建议需区分，具体使用范围见各技能入口及来源说明。动态政策、医疗、法律与金融信息按实际问题另行核验。
