# 低增长时代个人生存策略 · survival-guide-downturn

![Version](https://img.shields.io/badge/version-3.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Format](https://img.shields.io/badge/format-Agent%20Skill-orange)

在经济下行、收入不稳或人生转折中，帮助你稳住基本生活、理清取舍，并增加有价值的选择。它覆盖现金流、工作、居住、照护、健康、关系和权益，也允许安稳、陪伴与休息成为正当目标。

## 如何使用

将**整个 `survival-guide-downturn` 文件夹**放入目标工具支持的技能目录，保留 `SKILL.md` 与 `references/` 的相对位置；具体安装路径按所用工具文档。只复制入口文件会丢失各领域指导。

可以直接提出问题：

- “失业了，储蓄还能撑两个月，家里还有老人要照顾，先做什么？”
- “稳定工作和自由职业怎么比较？我不想创业。”
- “想换个生活成本低的城市，但担心照护和医保衔接。”
- “帮我全面盘点现在的生活，我希望多一点时间陪家人。”

具体问题只处理相关领域，全面盘点才扩展范围。不会因为出现LPR、利率倒挂等词，就自动开始人生评估。

## 3.0的变化

| 原设计 | 本版处理 |
| --- | --- |
| 长单文件、固定顺序、每次至少五个维度 | 短入口和按需模块，按本次问题决定范围 |
| 90/10、固定现金月数、固定副业进度 | 依据现金流、责任、损失承受能力与用户目标选择 |
| 大承诺统一延后12个月 | 比较关键缺失信息、等待成本、可逆性和真实截止 |
| 用“生产性”定义安全借款 | 看真实偿债来源、波动、担保、期限及退出成本 |
| 自编心理症状计数与求助阈值 | 非诊断性求助提示，持续困扰可评估，即时危险优先处理 |
| 法规、试验、作者与网友经验混排证据等级 | 区分每种来源能支持的具体主张，动态事实临场查证 |
| 主要防范被锁定和被利用 | 同时加入个人方向、够用标准、正向支持与共同责任 |

入口见 [SKILL.md](SKILL.md)，各模块位于 [references](references/)。原有财务、保险、技能、迁居、健康、照护、维权、防骗和身后事务能力仍保留，按需要使用。

## 来源与范围

本版定向复核了《The 5 Types of Wealth》《Your Money or Your Life》《Anything You Want》《Principles》《巨婴国》的相关部分；《紫丸》和《社交博弈策略全识别手册》使用已有筛选摘要，并重新核对源文件同一性。没有宣称本轮重读所有书籍。

公开材料保留了可读的Reddit边界讨论、Sivers官方澄清及James Clear起步工具。X与Quora入口访问失败，未纳入其帖子或高赞结论。作者书籍和自己的文章不算独立验证。

详细范围、定位与限制见 [sources-and-evidence.md](references/sources-and-evidence.md) 和 [field-notes.md](references/field-notes.md)。安装包不含电子书、扫描件、个人资料或全文摘录。

## 使用边界

这是生活规划与决策支持工具。具体医疗、法律、保险和金融问题需相应专业支持及当前当地资料；政策、金额、产品条款和援助号码不能沿用历史值。技能提供问题梳理、材料准备和核实路径，不代替用户购买、签约、提交申请或联系第三方。

本版不要求额外安装其他技能，联网与账户不可用时会说明未核验事项。建议的实际效果仍需根据个人处境和后续反馈评估。
