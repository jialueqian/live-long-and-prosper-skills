## 这是什么

一个可直接加载到 AI 编程/对话工具（Qoder、Claude Code 等支持 Agent Skill 的环境）的策略顾问技能，单文件 `SKILL.md`，约 4 万字节。

它把"低增长时代个人该怎么办"这个宏大而模糊的问题，拆成一条**可执行的闭环流水线**：

```
处境诊断（14 维度）→ 认知校准 → 宏观周期定位 → 财务安全网 → 保险
→ 收入与技能资产化 → 空间与迁移自由 → 注意力与能量管理 → 赡养抚养
→ 心智与关系 → 法律维权 → 身后事务 → 输出按价值序列排序的行动方案
```

并以**底线防护清单（8 项季度自查）**和**质量检查清单**收尾，保证输出可落地、可复盘。

## 核心设计

| 设计 | 说明 |
|------|------|
| **价值序列排序（字典序）** | 死亡 > 自由 > 结构性锁定 > 金钱 > 时间/精力。拒绝"损失÷成本"的伪精确加权——不同量纲的东西不该相除 |
| **杠铃策略** | 90% 极度安全 + 10% 高凸性实验。同时防两种失败：纯防御（等死）与纯进攻（找死），含"过度防御"纠偏 |
| **证据分级 + 三维成本** | 每条建议标注 A/B/C 证据等级（A=随机试验/法条原文，B=官方指导/观察性研究，C=经验推演）与钱/时间/毅力成本 |
| **好债务 / 坏债务判别** | 债务只用于生产性用途——签字前问"这笔钱未来能自己产生还本付息的现金流吗" |
| **宏观周期定位（含中国语境转译）** | 利差信号 → 判别规则（长期有效）与时间戳示例（会过期）分离；落地中国时对照 LPR / 社融 / 中债利差，而非直接套用美债框架 |
| **不可逆延迟、可逆加速** | 买房/结婚/大额贷款观察 ≥12 个月；学技能/接项目/试新方向立刻做 |

## 内容结构

```
SKILL.md
├── 核心理念（9 条，贯穿全流程）
├── 执行流程
│   ├── 第一步  处境诊断（14 维度：杠杆/收入结构/保险/心理/债务用途/K 型位置…）
│   ├── 第二步  认知校准（低增长/去房产化/K 型分化/幸存者偏差/可逆 vs 不可逆）
│   ├── 第 2.5 步 宏观周期定位（三组关键词诊断 + 利率曲线判别规则 + 中国语境转译表）
│   ├── 第三步  财务安全网（四层现金池 + 杠铃策略）
│   ├── 第 3.5 步 保险（风险金字塔优先级：百万医疗→重疾→定寿→意外）
│   ├── 第四步  收入与技能资产化（卖时间→卖技能→卖产品；雇佣形态长期账）
│   ├── 第五步  空间与迁移自由（出海逻辑与数据支撑 + 国内替代路径）
│   ├── 第六步  注意力与能量管理（含 DSM-5 心理危机识别与求助渠道）
│   ├── 第 6.5 步 赡养与抚养（三明治一代的医保/护理/教育金策略）
│   ├── 第七步  心智与关系（含防诈骗三铁律与止付黄金动作）
│   ├── 第 7.5 步 法律维权（官方免费救济通道 + 关键时效 + 法律红线）
│   ├── 第 7.6 步 身后事务（事前准备 + 事后六步流程）
│   └── 第八步  输出行动方案（强制按价值序列字典序排序）
├── 底线防护清单（8 项，每季度必查）
├── 质量检查清单（含防"过度防御"检查项）
├── 数据来源与参考书目（交叉验证）
└── 重要局限性 & 何时寻求专业帮助
```

## 如何使用

1. 将 `SKILL.md` 放入你的 Agent 工具的技能目录（如 Qoder 的 `skills/survival-guide-downturn/`，或 Claude Code 的 `~/.claude/skills/`）
2. 直接提问即可触发，例如：
   - "全面诊断"——走完整 14 维度评估并输出行动方案
   - "要不要买房 / 要不要辞职 / 要不要加杠杆"——走对应模块
   - "失业了怎么办 / 被欠薪 / 利率倒挂什么意思"——定向调用
3. 触发词（详见 frontmatter `description`）：躺平指南、生存指南、低增长怎么办、经济下行、K 型分化、周期判断、LPR、社融……

> ⚠️ 宏观数据时效声明：第 2.5 步的**判别规则**长期有效，但任何"当前利差/政策立场"类描述都会过期。涉及加杠杆/买房/大额负债决策前，请自行查询当下数值（LPR、社融、国债利差），不要引用文档中的历史状态作为当下依据。

## 数据来源与证据分级

本 Skill 由三部分交叉验证而成：

| 来源 | 性质 | 贡献 |
|------|------|------|
| 《历史垃圾时间躺平生存指南》56 条 | 民间生存策略合集，经 15 本国际著作交叉验证 | 核心理念、杠铃策略、可逆/不可逆框架 |
| 《高性价比人生指南》528 条 | 开源书（Unlicense 公有领域），逐条引期刊论文与官方文件 | 法律维权/身后事务/保险/救济通道的 A/B 级流程与数字 |
| 《见证逆潮》（付鹏，2023） | 宏观专家框架著作 | 宏观周期定位、好债务/坏债务、日/港/美分化史料 |

**《见证逆潮》引用约定**：观点性论述（三组关键词、三级分工、K 型机制等）按 **C 级（专家推演）**对待——是高质量参考框架，不是已被证实的定律；书中转引的一手统计数据（IMF/各国央行/统计局口径）按 **B 级**对待。全文引用处均标注 `§章节号` 便于回溯。

参考书目：Antifragile / The Psychology of Money / Die with Zero / The Almanack of Naval Ravikant / Company of One / Why We Sleep / DSM-5 / AFP·CFP 标准教材 等（完整清单见 SKILL.md 末尾）。

## 局限性与免责

- 本 Skill **不能替代**：心理咨询/精神科治疗、医疗建议、持证律师、持证财务顾问、自杀预防热线
- 涉及具体法律纠纷、严重负债违约（逾期 >90 天）、家庭成员重病无保、成瘾行为时，应寻求专业帮助而非人生规划
- 文档中热线与政策数字（失业金月数、低保标准、医保缴费）具有时效性且各地不同，请以当地现行政策为准
- 心理援助：**全国统一心理援助热线 12356**；紧急情况请拨打 110 或前往最近医院急诊科
